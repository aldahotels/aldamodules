Include the tools in the MCP server of each person that needs them. The read
tools need no further set-up and only show the tickets of the hotels of the
user (and the tickets without hotel). For the two write tools, set the users
allowed in *AI > AI Tool* and tick *Write enabled*, as explained in
``pms_ai_tool``.

A ticket is open while its stage is not folded. In the backlog, the age is
counted from the creation of the ticket.
